# Pre-CV Dimensions Map

This is a checklist to draw from when expanding pre-CVs later. It is *not* a required template or a fixed section order. Sections can appear in any order, be partially filled, duplicated, or omitted entirely.

## Core
- [ ] Personal details (minimal/hinted only; avoid full addresses, emails, phone numbers, ID numbers)
- [ ] Power statement / pitch
- [ ] Personal/professional summary
- [ ] Location/preferences (region/country/hybrid/remote/open to relocation) 

## Professional Story
- [ ] Work/employment experience
- [ ] Research experience
- [ ] Projects (personal/professional)
- [ ] Accomplishments / achievements
- [ ] Career breaks/gaps (only if implied, vague)

## Credentials
- [ ] Education / qualifications
- [ ] Professional training
- [ ] Licenses and certifications
- [ ] Affiliations/memberships

## Skills
- [ ] Working skills (naked, no ratings/bars/stars)
- [ ] Technical proficiencies (may overlap with experience)
- [ ] Tools/platforms (only if hinted at, not exhaustively listed)

## Supplementary
- [ ] Additional details (driving licence, clearance, availability, etc.)
- [ ] Languages
- [ ] Volunteering
- [ ] Extracurricular activities / hobbies
- [ ] Conferences / talks
- [ ] Awards (may overlap with accomplishments)
- [ ] References (hint only, never full details)

## Online/Social
- [ ] Websites / portfolio
- [ ] Professional social links

## Variation Axes (to maximise diversity)
- [ ] **Seniority/level**: entry, junior, mid, senior, lead, specialist/trades, higher/management
- [ ] **Sector**: IT, engineering, finance, management, sales, marketing, HR, skilled trades, specialists, misc/random
- [ ] **Language**: English, Spanish, French (only these — well-supported and parse-friendly for language models/extraction; avoid others for now)
- [ ] **Origin / Education location**: different countries for schooling/university (varied naming/formatting; only hinted at if included)
- [ ] **Work availability**: if ever included, vary (full-time/part-time, shifts, notice period, relocation, right-to-work). Leave out by default.
- [ ] **Depth**: sparse (1-2 lines) -> patchy -> detailed in a single area only
- [ ] **Focus**: story-first, skill-first, credential-first, project-first, social/volunteer-first, or no clear focus
- [ ] **Quality**: rough/impressionistic, generic, oddly specific in one niche, polished-but-vague
- [ ] **Profile type**: direct, career-changer, returner after a gap, specialist, generalist
- [ ] **Completeness**: partial on purpose. Omit sections deliberately rather than inventing filler

## Workflow (to be followed for each new template)
1. **Read the pre-CV** and note the impression/tone/sections/skills/creds/extras/timeline
2. **Choose variability axes** (language, seniority, sector, origin, availability, focus, quality, completeness) — one by one, explicitly
3. **Choose sections** that make sense for the role and candidate (don't force template sections) — consider what's plausible for this pre-CV
4. **Expand content section by section** (one by one, not in parallel), with plausible details and proper line breaks
5. **Note variability trace** in the final MD (what was chosen and why)
6. **Fit to template** (template is presentation layer, not content driver — if later it can't fit, rewrite, but initially content should be independent of template details)
7. **Compile and mark done**

**Important**: Do NOT optimize the process into a single production/write. The step-by-step explicit choices (language, city, university, seniority, sections, etc.) are what produce realistic and varied content. Skipping this leads to non-interesting CVs that are constrained to template details rather than reflecting real candidate variety.

*Note:* Exact personal info, exact employers/schools/locations, full skill lists, and full certification lists are intentionally left for a later pass once templates are available.
